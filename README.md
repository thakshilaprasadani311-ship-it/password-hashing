# Password Hashing Login System

A simple Python application that demonstrates secure password hashing and authentication using the bcrypt library.

## Features

- User registration with a username and password
- Secure password hashing using bcrypt
- Password verification during login
- Login success and failure messages

## Technologies Used

- Python
- bcrypt

## How It Works

1. The user enters a username and password.
2. The password is converted into a secure hash using bcrypt.
3. The hashed password is used for authentication.
4. When the user logs in, bcrypt checks whether the entered password matches the stored hash.
5. The application displays a login success or failure message.
